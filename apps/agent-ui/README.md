# Agent Demo UI

Mastra AIエージェントとワークフローを利用するフロントエンドアプリケーション。

## 機能

- UX評価ワークフローの実行
- UXエージェントとのチャット

## 必要条件

- Node.js 18以上
- Mastra APIサーバー（agent-demoプロジェクトのagentディレクトリ）

## セットアップ

1. 依存関係のインストール:

```bash
npm install
```

2. 環境変数の設定:

`.env.local`ファイルをプロジェクトルートに作成し、以下の内容を追加してください：

```
# Mastra API URL
MASTRA_API_URL=http://localhost:4111
```

## 実行手順

1. まず、Mastra APIサーバーを起動します:

```bash
# agent-demoプロジェクトのagentディレクトリに移動
cd ../agent

# Mastraサーバーを起動
npm run dev
```

2. 別のターミナルで、このUIアプリを起動します:

```bash
# agent-uiディレクトリで
npm run dev
```

3. ブラウザで http://localhost:3000 にアクセスしてアプリケーションを使用します。

## 使用方法

### UX評価の実行

1. 「UX評価を開始」セクションで評価したいサイトのURLを入力します
2. オプションで追加パラメータを設定します
3. 「UX評価を開始」ボタンをクリックします
4. 評価結果が表示されるのを待ちます

### エージェントとのチャット

1. 「エージェントとチャット」セクションでメッセージを入力します
2. 「送信」ボタンをクリックします
3. エージェントからの応答が表示されます
