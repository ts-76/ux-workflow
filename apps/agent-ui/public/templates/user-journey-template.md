## 記入時の注意事項

### ✅ 記入のポイント
1. **時系列の一貫性**: フェーズ間の論理的つながりを確保
2. **感情の変化**: 各フェーズでの感情の変化を詳細に記録
3. **具体的行動**: 抽象的ではなく具体的な行動を記述
4. **阻害要因の特定**: 各フェーズでの離脱要因を明確に
5. **ページアクセス順序の論理性**: ユーザーの目的に沿った自然なページ遷移を設計
6. **ペルソナ固有の行動パターン**: 各ペルソナの特徴を反映したページアクセス行動を記述

### ❌ 避けるべきこと
- 理想的すぎるジャーニー（現実的な障壁を無視）
- 感情の記述不足（行動のみに注目）
- フェーズ間の矛盾（前フェーズとの整合性不足）
- 一般論（ペルソナ固有の特徴を反映しない）
- 非現実的なページ遷移（ユーザーが実際に取らない行動パターン）
- ページアクセス順序の一貫性不足（フェーズ間での矛盾）

### 💡 記入例

#### 行動記述の例
**良い例**: 「技術仕様書をダウンロードし、既存システムとの互換性を30分かけて確認。API仕様が不明確で不安を感じ、営業担当に電話で質問」
**悪い例**: 「情報を調べて検討した」

#### ページアクセス行動の例
**良い例**: 「トップページ → サービス概要 → 料金プラン → 導入事例（IT企業の事例を重点的に確認、15分滞在）→ 技術仕様 → FAQ（セキュリティに関する質問を重点確認）→ 問い合わせフォーム」
**悪い例**: 「ウェブサイトを見た」
